# Humanitarian Crisis Mapping (Module Overview)

FocalPoint OS includes a lightweight crisis overview structure intended for coordination dashboards.

## Design Principles
- Public sources only
- Clear attribution
- Suitable for humanitarian and NGO staff
- Not a replacement for official UN / cluster assessments

## Current capabilities
- Structured crisis overview by region
- Key themes (food security, displacement, access, protection)
- Ready to be visualised on a simple map layer later (Leaflet / Mapbox)

## Future extension ideas
- GeoJSON export of public hotspot areas
- Simple choropleth by county / admin unit
- Linkage to Travel Risk Packs for the same geography
